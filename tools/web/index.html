FM-1 firmware tool

Install the firmware on your M-VAVE FM-1 and manage its patches, from this page over USB-MIDI. Nothing is uploaded anywhere. Use Chrome or Edge (Safari has no Web MIDI).

Install

Plug the FM-1 in by USB, switch it on and press Install (about a minute; keep the page open and the cable in). An update of the same firmware keeps its patches; another firmware may erase them: back them up below first. If anything goes wrong: hold OCT- while switching on (the USB rescue), and install again.
